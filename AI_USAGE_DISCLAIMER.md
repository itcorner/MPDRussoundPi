- Parts of the code, documentation, refactors, and tests may have been generated or suggested by AI.
- Human review, testing, and validation are still required before production use.

Final responsibility for architecture, correctness, security, licensing compliance, and operational safety remains with the human maintainers.

## Recommendation for Contributors

If you contribute AI-assisted changes, please:

- review all generated code before committing,
- run relevant tests and linters,
